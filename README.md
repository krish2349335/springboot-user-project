# Spring Boot User Project

A simple Spring Boot application demonstrating basic CRUD operations
on a User entity using Spring Data JPA and MySQL.

## Features
- Create User
- Get User by ID
- Get Users by Age
- Update User details
- Spring Data JPA Repository usage

## Tech Stack
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven

## Project Structure
- Entity → User entity
- Repo → UserRepository (JPA)
- 'application.properties'→ Database configuration

## How to Run
1. Clone the repository
2. Update MySQL credentials in 'appli.cation.properties'
3. Run the Spring Boot application
